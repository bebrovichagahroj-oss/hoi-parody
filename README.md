# Хойка-пародия: Гримания 1936

Браузерная пародия на grand strategy про Гриманию и её соседей. Всё работает локально: один `index.html` и `game.js`, без внешних библиотек, серверов и интернета.

## Запуск

Откройте `index.html` в любом современном браузере — двойным кликом.

## Цель

Захватить **55% провинций** континента. Потеря столицы означает капитуляцию и конец партии.

## Управление

| Действие | Как делать |
|---|---|
| Выбрать провинцию | Левый клик по гексу |
| Атаковать | Сначала своя провинция, затем соседняя чужая → кнопка «Атаковать» |
| Перебросить 1 дивизию | Выбрать свою провинцию, ПКМ по соседней своей |
| Перебросить все дивизии | Shift + ПКМ |
| Набрать дивизию / построить завод | Кнопки в панели провинции |
| Фокусы | Кнопка «Фокусы» или `F` |
| Дипломатия | Кнопка «Дипломатия» или `D` |
| Помощь | `H` |
| Пауза / скорость | Пробел, `1`, `2`, `3` или кнопки внизу |
| Масштаб и карта | Колесо мыши, перетаскивание |

## Что происходит в игре

- Экономика: заводы дают снаряжение, провинции — людей и политическую власть. Дивизия стоит 50 снаряжения и 10 тыс. человек, а также требует ежедневного довольствия.
- Сражения идут по дням: местное превосходство решает исход. Оборону усиливают леса, горы, города и столичный бонус. В каждой провинции есть ополчение, поэтому пустые гексы не сдаются мгновенно.
- Страны живут своей жизнью: объявляют войны, подписывают пакты, набирают армии и наступают.
- Случайные события с выбором, национальные фокусы, мировая напряжённость.
- Всё на русском, с пародийными названиями провинций вроде «Штутгарт-на-шее» и «Пицца-Наполи».

Победить можно, сосредоточив войска в одном гексе и захватывая столицы: при падении столицы страна передаёт противнику все свои провинции.
